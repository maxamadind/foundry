Maxamad Industries is an invention company. Foundry is invention #1: the
machine that turns any expert's book into a cited AI agent. Business model:

agent, revenue is shared 70/30.

## The honest gap this package surfaced

Code inspection on 2026-10-04 confirmed three launch blockers that do not
exist in the app yet: (1) consent/privacy notice on chat pages, (2)
conversation logging (the quality + data-flywheel foundation — must follow
consent), (3) "this is software, not the expert" disclosure on agent pages.
These are flagged as must-build items in the checklist, section C.
